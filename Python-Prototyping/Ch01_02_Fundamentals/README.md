# Ch01-02 数字图像基础(阶段 1,第 2~3 周)

> 目标:理解图像在内存中的本质;掌握插值与几何变换 —— 视频缩放的根基。

## 阅读范围

- 第 1 章泛读
- 第 2 章:精读 2.4(采样与量化,重点插值)、2.5(像素间关系)、2.6(数学工具:算术运算、几何变换);2.1~2.3 泛读

## 核心知识点

- **采样与量化**:空间分辨率与灰度分辨率;位深下降导致伪轮廓
- **像素间关系**:4/8/m 邻域;欧氏距离、城市街区距离
- **图像插值(重点)**:最近邻、双线性、双三次 —— 视频帧缩放的底层
- **算术运算**:多帧平均降噪、图像相减
- **几何变换**:仿射变换矩阵、逆向映射(目标→源)

## 实践任务

- [ ] 手写最近邻 + 双线性插值缩放,与 `cv2.resize` 对比
- [ ] 手写仿射变换(旋转+缩放),用逆向映射实现
- [ ] 多帧平均降噪:加噪 N 次取平均,验证噪声随 N 下降

## 验收问题

- 位深从 8 位降到 4 位图像会发生什么?
- 双线性为什么比最近邻平滑?双三次为什么更锐?
- 几何变换为什么用逆向映射而不是正向映射?

> 注:反色/对数/Gamma 等灰度变换在第四版属于 3.2 节,见 `Ch03_Spatial_Filtering/`。
