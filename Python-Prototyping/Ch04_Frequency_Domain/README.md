## 核心知识点

- **2D DFT**:幅值谱与相位谱、`fftshift` 中心化、共轭对称性
- **卷积定理(核心)**:空域卷积 = 频域乘积
- **频域滤波**:理想/巴特沃斯/高斯低通(理想低通的振铃);高斯高通、频域拉普拉斯;带阻/陷波(去周期噪声)
