# Ch09 形态学图像处理(阶段 5,第 15~17 周)

> 目标:掌握二值图像的形态学操作,用于 Mask 修饰与噪点去除(毕业项目绿幕抠图的关键一环)。

## 阅读范围

- 精读 9.1~9.3(结构元、腐蚀膨胀、开闭运算)
- 精读 9.5 中的边界提取、孔洞填充、连通分量
- 泛读灰度形态学(顶帽/底帽变换)

## 核心知识点

- **结构元素** (Structuring Element)
- **膨胀**(扩大白色区域)与 **腐蚀**(缩小白色区域)
- **开运算**:先腐蚀后膨胀 —— 消除小噪点、打断细长连接
- **闭运算**:先膨胀后腐蚀 —— 填补小孔洞、桥接断裂
- 边界提取、孔洞填充、连通分量标记

## 实践任务

- [ ] 手写二值腐蚀/膨胀,组合出开/闭运算,清理一张带噪 mask
- [ ] 连通分量标记,统计目标个数

## 验收问题

- 开运算和闭运算分别适合处理什么缺陷?顺序为什么不能随便换?
- 结构元的形状和大小如何影响结果?
