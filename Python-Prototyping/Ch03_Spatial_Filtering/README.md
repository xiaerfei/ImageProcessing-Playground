# Ch03 灰度变换与空间滤波(阶段 2,第 4~7 周,全书核心)

> 目标:掌握图像增强的核心手段(点变换、直方图、平滑、锐化),滤镜开发的基础。

## 阅读范围

- 精读 3.1~3.6:基本灰度变换(3.2)、直方图处理(3.3)、空间滤波基础(3.4)、平滑(3.5)、锐化(3.6)
- 泛读 3.7~3.8

## 核心知识点

- **基本灰度变换**:反色、对数变换(扩展暗部)、幂律 (Gamma) 校正、分段线性
- **直方图处理**:均衡化(CDF 映射)、直方图匹配、局部增强(CLAHE)
- **空间滤波基础**:卷积 vs 相关、核 (Kernel)、边界填充(zero/replicate/reflect)、**可分离核**(O(k²) → O(2k))
- **平滑(低通)**:盒式滤波、高斯滤波;中值滤波(非线性,去椒盐噪声)
- **锐化(高通)**:拉普拉斯算子、Unsharp Masking、Sobel 梯度
