# Ch06 彩色图像处理(阶段 3,第 8~9 周)

> 目标:系统梳理色彩空间与全彩处理;补齐书里不细讲、但推流工作核心的视频色彩工程知识。
> 放在第 3 章之后学,因为彩色变换/平滑锐化(6.5、6.6)大量复用空域滤波概念。

## 阅读范围

- 精读 6.1~6.2(色彩基础、颜色模型)、6.4~6.6(全彩处理、彩色变换、彩色平滑与锐化)
- 泛读 6.3(伪彩色);6.7(基于彩色的分割)留到阶段 5 前回看

## 核心知识点

- **颜色模型**:RGB、CMY/CMYK、HSI/HSV(色调、饱和度、亮度)
- **彩色变换**:补色、彩色分层、色调/饱和度调整
- **彩色平滑与锐化**:逐通道处理 vs 亮度通道处理的差异

## 书外必补(视频色彩工程)

- YCbCr 的 **BT.601 / BT.709 / BT.2020** 三套系数;**full range vs video range**(Y: 16~235)
- 色度下采样 **4:4:4 / 4:2:2 / 4:2:0**,NV12 / I420 内存布局
- 参考(选):Poynton《Digital Video and HD》
