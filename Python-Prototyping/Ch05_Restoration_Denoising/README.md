# Ch05 图像复原与去噪(选修 A,约 2 周)

> 主线毕业后按需选修。适合关心弱光推流画质的场景。

## 阅读范围

- 5.1~5.4:图像退化模型、噪声模型(高斯、椒盐等)、仅有噪声时的空域复原(均值族滤波器、统计排序滤波器、自适应滤波)、周期噪声抑制
- 跳过:退化函数估计、逆滤波/维纳滤波之后的重建内容(需要时再回来)

## 核心知识点

- 常见噪声模型及其直方图特征
- 算术/几何/谐波/逆谐波均值滤波器的适用场景
- 自适应中值滤波

## 书外延伸(工程价值高)

- **双边滤波**:保边平滑,美颜磨皮的基础
- **非局部均值** (NLM)
- **视频时域/时空联合降噪**:多帧信息利用,推流弱光场景的核心手段

## 实践任务

- [ ] 生成不同噪声类型,观察各自直方图特征
- [ ] 对比中值 / 自适应中值在高密度椒盐噪声下的表现
- [ ] 手写双边滤波,对比高斯滤波的保边效果
