# Ch08 图像压缩(选修 B,约 2~3 周)

> 主线毕业后选修 —— **对推流开发者价值最高的一章**:DCT、量化、块效应、运动补偿正是 H.264/HEVC 的理论原型。

## 阅读范围

- 8.1:压缩基础(编码冗余、空间冗余、不相关信息;信息熵;保真度准则)
- 块变换编码一节:**DCT、JPEG 完整流程、量化表、块效应**
- 预测编码一节:差分编码、**运动补偿**(视频帧间预测的原型)
- 泛读:霍夫曼编码、算术编码、行程编码
- 跳过:小波编码、水印(需要时再看)

## 核心知识点

- 三类冗余与信息熵:压缩的理论上限
- JPEG 流水线:分块 → DCT → 量化(有损的唯一一步)→ Z 字扫描 → 熵编码
- 量化强度与块效应的关系
- 预测编码与运动补偿:I 帧/P 帧的理论根源

## 实践任务

- [ ] 手写 8×8 DCT + 量化 + 反变换,观察不同量化强度下的块效应
- [ ] 实现简单差分预测编码,对比熵变化
- [ ] 计算一张图的信息熵,对比 PNG/JPEG 实际压缩率

## 验收问题

- JPEG 哪一步是有损的?量化表为什么高频部分数值更大?
- 块效应为什么发生在 8×8 边界上?
- 帧间预测为什么能大幅压缩视频?什么场景下失效(剧烈运动、场景切换)?
