## 核心知识点

- **边缘检测**:梯度算子 → Canny(高斯平滑 → 梯度 → 非极大值抑制 → 双阈值滞后连接)
- **阈值处理**:全局阈值、Otsu(类间方差最大化)、自适应阈值(应对光照不均)
- **区域方法**:区域生长、k-means / 超像素、分水岭(了解)
