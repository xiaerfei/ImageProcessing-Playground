## 二、逐阶段

### 阶段 1 直觉

| 项目 | 内容 |
| :--- | :--- |
| 学什么 | 卷积(convolution)、傅里叶分解的动画直觉 |
| 要理解 | 卷积 = 滑动窗口里加权平均;任何信号 = 一堆转圈 $e^{i\omega n}$ 的叠加 |
| 计算 | 一道:8 个箭头 $e^{i2\pi km/8}$ 相加,$k=0$ 得 8,$k=1..7$ 得 0 |
| 掌握到 | 能口述,不推公式 |
| 完成标准 | 说清「模糊笔刷为什么让图变模糊」(变化快的地方被平均掉) |
| 对应 DIP | 后面所有滤波 |

### 阶段 2 LTI 与卷积

| 项目 | 内容 |
| :--- | :--- |
| 学什么 | 线性、时不变(LTI)、冲激响应(impulse response);入门看[理解卷积](快速路线/1.理解卷积.md)(馒头比喻) |
| 要理解 | LTI 系统由冲激响应完全决定,输出 = 输入卷冲激响应 |
| 计算 | $[1,2,3]*[1,1]=[1,3,5,3]$;$[0,0,4,4,4]$ 过 $[1,2,1]/4$ 得 $[0,0,1,3,4,3,1]$ |
| 掌握到 | 会判断一个操作是不是 LTI |
| 完成标准 | ① $y=x+1$ 为什么不是线性(输入全 0 输出不为 0);② Sobel 的两个核是 LTI,但梯度幅值 $\sqrt{G_x^2+G_y^2}$ 不是线性的;③ 中值滤波不是卷积 |
| 对应 DIP | 第 3 章平滑、锐化、边缘检测 |

### 阶段 3 傅里叶

| 项目 | 内容 |
| :--- | :--- |
| 学什么 | DFT、卷积定理、补零、频率响应(frequency response)、幅度谱与相位谱 |
| 要理解 | DFT = 用 $N$ 个转圈探针和信号做内积;转圈的零件过 LTI 只被缩放,所以卷积 = 频域相乘 |
| 计算 | 手算 4 点 DFT:$[1,2,3,4]\to[10,\,-2+2i,\,-2,\,-2-2i]$;核的 $H(0)$ = 系数和,$H(\pi)$ = 交错和 |
| 掌握到 | 4 点能手算,更大交给 `np.fft`;小核一眼判低通高通 |
| 完成标准 | ① $[1,2,1]/4$:$H(0)=1$、$H(\pi)=0$,低通;$[1,-1]$:0、2,高通。② DFT 相乘是循环卷积:$[1,2,3,4]$ 与 $[1,1,0,0]$ 得 $[5,3,5,7]$,线性卷积是 $[1,3,5,7,4]$,补零到 $N+M-1$ 才相等。③ `fft2` 的直流在 $[0,0]$ 角落,`fftshift` 后才在中心。④ 平移只改相位、幅度不变;拿 A 的幅度配 B 的相位,重建图像 B(camera/coins 实测相关 0.574) |
| 对应 DIP | 4.2、4.4 一维直觉;4.6~4.9 频域滤波的补零与低通高通 |

### 阶段 4 采样与混叠

| 项目 | 内容 |
| :--- | :--- |
| 学什么 | 采样定理、奈奎斯特频率、混叠(aliasing) |
| 要理解 | $f$ 与 $f\pm f_s$ 采出来完全一样,高于 $f_s/2$ 的频率会折叠成假的低频 |
| 计算 | $f_s=8$ kHz 时 5 kHz → 3 kHz,7 kHz → 1 kHz,8 kHz → 0 |
| 掌握到 | 给 $f$ 和 $f_s$ 能算出表观频率 |
| 完成标准 | ① 说清 5 kHz 为何变 3 kHz;② 0.45 周期/像素的细纹隔点抽样,变成周期 10 像素的假粗纹(摩尔纹);③ 先过 $[1,2,1]/4$ 再抽样,假纹幅度从 1 降到 0.0245 |
| 对应 DIP | 4.3 采样;缩小图像、摩尔纹;你熟悉的音频重采样 |

### 阶段 5 二维

| 项目 | 内容 |
| :--- | :--- |
| 学什么 | 二维 DFT、`fftshift`、频谱图怎么看 |
| 要理解 | 二维 DFT = 先每行做一维再每列做一维;一条条纹在频谱上是一对亮点 |
| 计算 | 4×4 纯色(值 5):只有 $F[0,0]=80$;4×4 竖条纹(每行 $[1,0,-1,0]$):$(0,1)$、$(0,3)$ 两点,各 8 |
| 掌握到 | 看频谱图能说出亮点位置对应什么方向和疏密的条纹 |
| 完成标准 | 用一句话顺下三条链:高斯模糊(低通,压细纹);Sobel(差分核压低频,留边缘);缩小防锯齿(先低通再抽样) |
| 对应 DIP | 4.5 起,然后正式读第 4 章 |

## 四、和豆包的差别

- **新增阶段 4 采样与混叠**:原方案考摩尔纹,但没安排学。
- **阶段 3 补上补零、循环卷积**:频域滤波最常见的 bug 出在这里。
- **完成标准附答案**:原方案只靠口述,没法核对。
- **订正两处**:`fft2` 直接出来直流在角落而非中心;Sobel 的梯度幅值不是线性的。
- 3Blue1Brown 视频时长、「10 天」的估时我都没核实,本篇不按天数排。
