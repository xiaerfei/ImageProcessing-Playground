## 先讲人话

当年学得云里雾里,多半不是你不行,而是课本把连续、离散、时域、频域、
拉普拉斯变换(Laplace transform)、Z 变换(Z-transform)**同时摊开**,配上十几张性质表,却没人告诉你**主线只有一句话**:

> **把信号拆成一堆匀速转圈的小零件;线性时不变系统(下称 LTI 系统)碰到每个小零件,
> 只会把它缩放一下、转一个角度,不会变出新零件。**

整门课都围着这句话转(LTI 是 linear time-invariant 的缩写):

- 「转圈的小零件」就是欧拉公式里的 `e^{iωn}`(已经有笔记了:
  [如何直观理解欧拉公式](如何直观理解欧拉公式.md))
- 「拆」叫傅里叶分析,离散的版本是离散傅里叶变换(discrete Fourier transform,DFT)
- 「系统碰到零件会怎样」叫频率响应(frequency response)
- 时域里同一件事的写法,是卷积(convolution)

所以这条路线不按教材目录走,**沿着这句话走**:先有信号和系统这两个词,再有卷积,
再有「拆」(DFT),再有「系统碰零件」(频率响应),最后接上采样和二维。

为什么公式非碰不可?你已经知道「`[1,2,1]/4` 是低通」,但**为什么它把最细的条纹
抹成 0**,只有一行 `1 + 2e^{-iπ} + e^{-2iπ} = 0` 能让你看见。
只看结论,永远停在「知道」;碰一次公式,才是「看得见」。

你有一个别人没有的优势:做了 4~5 年音视频,采样率、混叠、滤波器天天在碰,
只是没人告诉过你背后是同一套数学。看到「5 kHz 在 8 kHz 采样下变成 3 kHz」
这种事,你会比纯学生更快反应过来。

## 一、目标与深度

### 学完要能做到什么

做到下面五条,Gonzalez 第 4 章就够用了:

1. 拿到一个 3~5 个数的核,**手算**出它是低通还是高通
2. 拿到一个 4 点信号,**手算**出它的 DFT,并说出每个点的意思
3. 说清楚「空域卷积 = 频域相乘」靠什么成立,以及补零为什么必须
4. 看到一张频谱图,说出条纹的方向和疏密对应在哪里
5. 解释 5 kHz 的声音在 8 kHz 采样下为什么变成 3 kHz,以及摩尔纹(moiré)是同一回事

### 三档深度

每个知识点只标一个目标档,**别在「认得」档上硬抠推导**:

| 档 | 意思 | 例子 |
| :--- | :--- | :--- |
| **认得** | 看到公式知道它在说什么,不要求会算 | 拉普拉斯变换的定义 |
| **会算** | 给几个数,能手算出结果 | 4 点 DFT、`[1,2,3]*[1,1]` |
| **会推** | 能自己把结论推出来 | 为什么 DFT 的探针互相正交 |

### 两条路径

| 路径 | 走哪几步 | 什么时候选 |
| :--- | :--- | :--- |
| **最短** | 数学热身 → 第 3、4、6、8 步(第 5、7 步用到再翻) | 只想尽快读第 4 章 |
| **完整(推荐)** | 数学热身 → 第 1~8 步,再走 `五、补全线` | 你说过「不系统学一下心里总是空」,那就走这条 |

完整路径并不长:第 1~8 步只覆盖离散那一半,连续和拉普拉斯放在最后,
**图像处理只用得上离散**。

## 二、数学热身

只补五块,每块一道过关题。**目标档都是「会算」**,不要求会推导技巧题。

| 块 | 用来干什么 | 过关题 |
| :--- | :--- | :--- |
| 复数与欧拉公式 | 一切频率分析的语言 | ① 算 `(2+i)(1−3i)`,并说它的模;写出 `e^{iπ/3}` |
| 三角恒等式 | 把 cos 拆成两个转圈 | ② 用 `cosθ = (e^{iθ}+e^{−iθ})/2` 推 `cosA·cosB` |
| 求和与等比数列 | DFT 里每一步化简 | ③ 算 `Σ 0.5ⁿ`(n=0..9),和 `Σ e^{i2πkm/8}`(m=0..7,k=0 与 k=1) |
| 内积与换基 | 傅里叶分析的本质 | ④ 把 `[3,1]` 在基 `[1,1]/√2`、`[1,−1]/√2` 下展开 |
| 积分 | 连续信号的写法 | ⑤ 算 `∫cos3x·cos3x`、`∫cos3x·cos5x`(0 到 2π) |

**先自己算,再看答案。** 复数这块已经在欧拉公式笔记里补过了,①②可以直接对着它做。

### 过关题答案

脚本第 0 块。

- **①** `(2+i)(1−3i) = 5−5i`,模 `√50 = 7.0711 = √5·√10`(**乘积的模 = 模的乘积**);
  `e^{iπ/3} = 0.5000+0.8660i`,而 `(e^{iπ/3}+e^{−iπ/3})/2 = 0.5000 = cos(π/3)`
- **②** 把 `cosA·cosB` 各拆成两项再乘开,得到四项:两项是 `e^{±i(A+B)}`,
  两项是 `e^{±i(A−B)}`,合起来正好是 `½[cos(A−B)+cos(A+B)]`;
  随机取两个角,两边相差 `2.0e-16`
- **③** `Σ 0.5ⁿ = 1.998046875 = (1−0.5¹⁰)/(1−0.5)`(n→∞ 时是 `1/(1−0.5) = 2`);
  `Σ e^{i2πkm/8}`:k=0 时 = **8**;k=1..7 时 **= 0**(实测最大模 `3.7e-15`)——
  八个箭头每个转 `45°·k`,首尾相接绕回原点。**这一道是第 4 步「探针互相正交(orthogonal)」的全部秘密**
- **④** 系数是 `2√2 = 2.8284` 和 `√2 = 1.4142`,还原回 `[3,1]`;
  能量 `3²+1² = 10 = 8 + 2`(系数的平方和不变)。**DFT 做的就是这件事,
  只是把基换成了 N 个转圈的**
- **⑤** `∫cos3x·cos3x = π = 3.1416`,`∫cos3x·cos5x = 0`(实测 `−0.0000`)。
  不用学积分技巧:用 ② 的积化和差,`cos3x·cos3x = ½[1+cos6x]`,
  转满整圈后 `cos6x` 部分积分为 0,剩下 `½·2π = π`

**连续那边的「正交」(⑤)和离散这边的「正交」(③)是同一个事实的两种写法**,
知道这一点,后面就不会觉得连续和离散是两门课。

## 三、路线一览

```text
数学热身 → 1 离散信号 → 2 系统 → 3 卷积 → 4 DFT → 5 DFT 的性质与坑
        → 6 频率响应 → 7 采样与混叠 → 8 进二维 → 回到 Gonzalez 第 4 章 → 补全线
```

顺序基本是线性的,只有两处依赖要记住:**第 6 步要用第 3 步(卷积)和第 4 步(DFT)**,
**第 7 步要用第 1 步(ω 与 ω+2π 等价)**。

| 步 | 主题 | 目标档 | 一句话 | 接哪里 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 离散信号 | 会算 | 信号 = 一串数;任何信号 = 冲激的加权和 | 第 11 周之前 |
| 2 | 系统 | 会算(判断) | 线性、时不变,以及「一个冲激响应管全部」 | 同上 |
| 3 | 卷积 | 会算 | 翻转、平移、相乘、求和;等价于多项式乘法 | [空间滤波基础](../05-spatial-filtering/01-spatial-filtering-basics.md) |
| 4 | DFT | 会算(4 点)、会推(正交) | 用 N 个转圈探针去和信号做内积 | ROADMAP 第 11 周 |

## 四、逐步推进

每一步固定五块:**学什么 / 学到什么程度 / 过关题 / 看视频时 / 图像里对应什么**。
先自己做过关题,再对答案;答不对,**回到这一步重学**,不要往后走。

### 第 1 步:离散信号

#### 学什么

- 离散信号就是一串数 `x[n]`(n 是整数):一行像素、一段音频采样,都是。
- 单位冲激(unit impulse)`δ[n]`:只有 n=0 处为 1,其余都是 0;
  单位阶跃(unit step)`u[n]`:n≥0 处全是 1。两者关系 `δ[n] = u[n] − u[n−1]`。
- **任何信号都是冲激的加权和**:`[3,1,2] = 3·δ[n] + 1·δ[n−1] + 2·δ[n−2]`。
  这一条是第 2、3 步的地基。
- 正弦序列 `cos(ωn)`,ω 的单位是「弧度/样本」。ω=π 最快(一正一负交替),ω=0 最慢(不动)。
- **周期**:`cos(ωn)` 是周期序列,当且仅当 `ω/2π` 是有理数。
- **ω 和 ω+2π 是同一个序列**,因为 `e^{i2πn} = 1`(n 是整数)。
  这是第 7 步混叠(aliasing)的根。

#### 学到什么程度

**会算**:判断是不是周期,并求最小周期。**会说**:为什么讨论频率只需要看 `[0, π]`。
**不要求**:连续信号里 `δ(t)` 的严格定义(涉及分布论,图像处理用不上)。

#### 过关题

1. `cos(2π·3n/8)` 的最小周期是多少?
2. `cos(n)` 是周期序列吗?
3. `cos(0.3n)` 和 `cos((0.3+2π)n)` 是什么关系?

**答案**(脚本第 1 块):① **8**(`3/8` 约分后分母是 8);
② **不是**,`ω/2π = 1/2π` 是无理数;实测 `cos(n)` 和 `cos(0.9n)` 在 5000 以内都找不到
使 `x[n+P] = x[n]` 的 P(容差 `1e-9`);③ **完全相同**,最大差 `3.7e-14`(就是浮点误差)。

#### 看视频时

课程里叫「信号的分类与基本运算」「离散时间信号」。**离散部分精看**;
连续信号的冲激 `δ(t)`、各种奇异函数略看。

#### 图像里对应什么

一行像素就是一个 `x[n]`;最细的条纹(亮暗交替)就是 ω=π;整行不变就是 ω=0。

### 第 2 步:系统

#### 学什么

- 系统就是**一个函数**:输入一串数,输出一串数。
- **线性**(叠加原理,superposition):`f(a·x₁ + b·x₂) = a·f(x₁) + b·f(x₂)`。
  一个必要条件:输入全 0,输出必须全 0。
- **时不变**(time-invariance):输入晚到 d 拍,输出也只是晚 d 拍,形状不变。
- **同时满足两条,就是 LTI 系统**,它有一个惊人的性质:
  用一个单位冲激去敲它,得到的输出叫冲激响应(impulse response)`h[n]`,
  **这个 `h` 就决定了它对任何输入的反应**(下一步的卷积)。

#### 学到什么程度

**会算(判断)**:给一个系统,判断线性与否、时不变与否,并举出反例。

#### 过关题

判断下面四个系统:

| 系统 | 线性? | 时不变? | 理由 |
| :--- | :--- | :--- | :--- |
| `y[n] = x[n] − x[n−1]` | 是 | 是 | LTI,冲激响应 `[1, −1]` |
| `y[n] = x[n]²` | **否** | 是 | `f(1+1) = 4`,而 `f(1)+f(1) = 2` |
| `y[n] = n·x[n]` | 是 | **否** | 喂 `δ[n]` 得全 0;喂 `δ[n−1]` 得 `δ[n−1]`,不是「全 0 右移一格」 |
| `y[n] = x[n] + 1` | **否** | 是 | 输入全 0 时输出全 1 |

最后一行很容易看漏:**加一个常数偏移不是线性运算**。

再来一道黑盒题:有一个不知道内部的 LTI 系统,你只能给它喂输入、看输出。
只喂一个冲激,读出 `h = [0.5, 0.3, 0, −0.2]`(之后全是 0);
再用 `x * h` 去**预测**一个随机输入的输出,与真实输出最大相差 `5.6e-17`(脚本第 2 块)。

#### 看视频时

「系统的性质」(线性、时不变、因果、稳定)**精看**。因果和稳定先认得即可。

#### 图像里对应什么

- 卷积核 = 冲激响应:往空白图的一个点上放一个亮点,滤出来的东西就是核
  (空间滤波篇里已经用单位冲激验证过)
- 中值滤波是非线性、调亮度是「加偏移」都**不是**卷积,
  见 [空间滤波基础 · 线性 vs 非线性](../05-spatial-filtering/01-spatial-filtering-basics.md)

### 第 3 步:卷积

#### 学什么

- 定义:`y[n] = Σ x[k]·h[n−k]`。读作:**把 h 翻转,在 x 上一格一格滑,每到一个位置,
  对应相乘再求和**。
- 长度:`N + M − 1`(长度 3 的和长度 2 的卷积,结果长 4)。
- **交换律、结合律、分配律**都成立。
- 和单位冲激卷积 = 原样;和 `δ[n−2]` 卷积 = 整体右移 2 格。
- **卷积就是多项式乘法**:`[1,2,3]` 看成 `1 + 2z + 3z²`,和 `[1,1]`(即 `1+z`)相乘,
  系数就是卷积结果。这是手算最不容易错的办法(第 6 步、补全线里会再用到)。

#### 学到什么程度

**会算**:长度 5 以内的两个序列手算卷积。**不要求**:连续卷积积分的计算技巧。

#### 过关题

1. `[1,2,3] * [1,1]`
2. `[1,2,3] * [1,0,−1]`
3. 用多项式乘法验证第 1 题
4. 把 `[0,0,4,4,4]`(一个陡峭的台阶)用 `[1,2,1]/4` 滤一遍

**答案**(脚本第 3 块):① `[1, 3, 5, 3]`,长 4;
手算其中 `y[2] = x[2]h[0] + x[1]h[1] + x[0]h[2] = 3 + 2 + 0 = 5`;
② `[1, 2, 2, −2, −3]`,长 5;
③ `(1+2z+3z²)(1+z) = 1 + 3z + 5z² + 3z³`,系数与 ① 一致;
④ `[0, 0, 1, 3, 4, 3, 1]`:**陡坡被抹成了 1、3、4 的斜坡**。

另有两个顺手验证:`[1,1]*[1,1] = [1,2,1]`(两个「盒子」卷一次就是三角核,
第 9 步会用上);交换律、结合律、分配律随机数验证,最大误差 `8.9e-16`
(浮点误差)。

#### 看视频时

「卷积和」「LTI 系统的时域分析」**精看离散卷积和**;连续的卷积积分略看,
知道它是「求和的极限」就够。

#### 图像里对应什么

二维卷积就是把上面的一维改成二维。翻转和不翻转的区别(相关 vs 卷积)已经在
[空间滤波基础](../05-spatial-filtering/01-spatial-filtering-basics.md)里讲过,这里不重复。

### 第 4 步:从换基到 DFT

#### 学什么

- **换基视角**:一个信号可以看成一堆「零件」的叠加,零件可以换。
  第 0 步的 `[3,1]`,既是 `3·[1,0] + 1·[0,1]`,
  也是 `2√2·[1,1]/√2 + √2·[1,−1]/√2`。**系数 = 信号和每个零件的内积**,
  前提是零件之间正交。
- **DFT 的定义**:`X[k] = Σ x[n]·e^{−i2πkn/N}`,k = 0..N−1。
  读作:**用 N 个「转 k 圈」的探针,依次和信号做内积**。
- 4 点时 `W = e^{−i2π/4} = −i`,它的幂是 `1, −i, −1, i`(脚本第 4 块)。
  **所以 4 点 DFT 只用加减和乘 ±i,能手算**。
- 逆变换:`x[n] = (1/N)·Σ X[k]·e^{+i2πkn/N}`,多一个 `1/N`。
- **为什么能还原**:探针互相正交,这正是热身③(`Σ e^{i2πkm/N} = 0`,k≠0)。
  矩阵写法:`F·Fᴴ = N·I`;实测 N=4 时最大偏差 `4.7e-16`,N=64 时 `3.2e-13`。
- 帕塞瓦尔定理(Parseval's theorem):`Σ|x|² = (1/N)·Σ|X|²`,能量守恒。
- 实信号的共轭对称(conjugate symmetry):`X[N−k]` 与 `X[k]` 互为共轭,
  所以**负频率不含新信息**。
- **k 对应的物理频率是 `k·fs/N`**(ROADMAP 第 11 周的自测题)。

#### 学到什么程度

**会算**:4 点 DFT。更大的 N 交给 `np.fft`。**会推**:探针为什么正交(热身③就是推导)。
**不要求**:快速算法(FFT)的推导,图像处理里只要知道它存在、是 DFT 的快速算法。

#### 过关题

手算下面五个 4 点信号的 DFT(**先别看答案**):

| x | X | 它在说什么 |
| :--- | :--- | :--- |
| `[1, 0, −1, 0]` | `[0, 2, 0, 2]` | 这是 `cos(2πn/4)` 的采样,k=1 和 k=3 两个点 |
| `[1, 1, 1, 1]` | `[4, 0, 0, 0]` | 全是直流,只有 k=0 |
| `[1, 0, 0, 0]` | `[1, 1, 1, 1]` | 一个冲激含所有频率 |
| `[1, 2, 3, 4]` | `[10, −2+2i, −2, −2−2i]` | 一般信号 |
| `[1, −1, 1, −1]` | `[0, 0, 4, 0]` | 最快的 ω=π,落在 k=N/2 |

五个结果与 `np.fft.fft` 最大相差 `2e-15`。

⚠️ **有的教材把 `1/N` 放在正变换里**:`F(ν) = (1/N)·Σ f(τ)·e^{−2πi(ν/N)τ}`,逆变换反而不带系数
(高等教育出版社那本《复变函数与积分变换》就是这样,见 `五、补全线` 的教材对照)。
它的例子写成 `{1 0 0 0} → ¼{1 1 1 1}`,而 `np.fft.fft([1,0,0,0])` 是 `[1, 1, 1, 1]`,
**差一个 N**。书上四个 N=4 的例子逐个核对,与 `np.fft / N` 的最大差是 `0.0`(脚本第 4 块)。
所以拿那本书的 DFT 结果对本篇的答案表时,先乘 N 或除 N,别以为自己算错了。

手算提示(以第一行为例):只有 n=0 和 n=2 两项非零,
`X[k] = 1·1 + (−1)·e^{−iπk} = 1 − (−1)^k`,所以 k 为偶数时 0,k 为奇数时 2。
第四行的 `X[1] = 1 + 2(−i) + 3(−1) + 4(i) = −2 + 2i`。

再做三个小问(脚本第 4 块):

1. `[1,2,3,4]` 的 `Σ|x|²` 与 `(1/N)Σ|X|²` 各是多少?
   **答案**:都是 **30**(`(100+8+4+8)/4`)

   **答案**:`−2+2i` 和 `−2−2i`,互为共轭

   幅值 `N/2·A = 32`

### 第 5 步:DFT 的性质与坑

#### 学什么

- **平移只转相位**:`[1,2,3,4]` 右移一格变成 `[4,1,2,3]`,
  `|X| = [10, 2.8284, 2, 2.8284]` **完全不变**,只是每个 `X[k]` 多乘了
  `e^{−i2πk/4}`(最大差 `6.3e-16`)。
- **循环卷积**(circular convolution):DFT 相乘对应的是**循环**卷积,不是线性卷积。
  `[1,2,3,4] ⊛ [1,1,0,0] = [5, 3, 5, 7]`,
  而线性卷积是 `[1, 3, 5, 7, 4]` —— 最后那个 4 **绕回去加到了第 0 项**(`1 + 4 = 5`)。
- **补零**:把两个序列都补零到 `N+M−1 = 5` 再相乘,结果就等于线性卷积(最大差 `8.9e-16`)。
  图像里的频域滤波为什么要「先补零到 2M×2N」,原因就在这里。
- **频谱泄漏**(spectral leakage):N=64 时,`cos` 恰好转整数圈(8 圈),
  能量最集中的 4 个点占 **100.00%**(其实只有 2 个点有值);
  转 8.5 圈,探针对不上,同样 4 个点只占 **81.08%**,剩下的泄漏到远处。
- **加窗**(窗函数,window function)压泄漏:8.5 圈的信号,在 k=20 处泄漏,
  矩形窗(也就是不加窗)是 `−23.9 dB`,汉宁窗(Hann)是 `−73.2 dB`(都相对各自峰值)。

#### 学到什么程度

**会算**:循环卷积与线性卷积的差别、补零长度。**认得**:窗函数,知道泄漏存在、
加窗可以压低,不必记各种窗的公式。

#### 过关题

1. `[1,2,3,4] ⊛ [1,1,0,0]` 是什么?线性卷积是什么?它们差在哪?
2. 为了让 FFT 相乘得到线性卷积,至少要补零到多长?
3. 为什么转 8.5 圈的 cos 会「漏」到远处?

**答案**:① 见上,差就是「绕回」;② `N + M − 1`(这里是 5);
③ 8.5 不是 `1/N` 的整数倍,没有任何一个探针刚好对得上它。

### 第 6 步:频率响应

**这一步是整门课的点睛,值得多花时间。**

#### 学什么

- **频率响应**:`H(ω) = Σ h[n]·e^{−iωn}`。把核当信号,对它做「连续 ω 版本的 DFT」。
- **复指数是 LTI 系统的特征函数**(eigenfunction):
  `e^{iωn}` 进去,出来还是 `e^{iωn}`,只是乘了一个复数 `H(ω)`。
  这个复数的模是缩放倍数,辐角是转过的角度。
- 实验:`cos(0.9n)` 过 `[1,2,1]/4`,输出**仍是 `cos(0.9n)`**,振幅 ×0.8108,
  正好等于 `(1+cos 0.9)/2`;输出与输入的相关系数是 `1.000000000000`,没有新频率。
- **判低通还是高通,不用画图**:
  `H(0) = 核的和`;`H(π) = 核的交错和`(`+,−,+,−…`)。
- `[1,2,1]/4`:`|H|` 在 ω = 0、π/2、π 处是 `1.0000`、`0.5000`、`0.0000`,
  即 `(1+cosω)/2`。
- `[1,−1]`:`|H|` 在同样三点是 `0.0000`、`1.4142`、`2.0000`,即 `2|sin(ω/2)|`。
- 5 点盒式 `[1,1,1,1,1]/5` 在 `ω = 2π/5` 处 `|H| = 8.3e-17`:**恰好被完全抹掉**。

#### 学到什么程度

**会算**:给 3~5 个数的核,算出 `H(0)`、`H(π)`,判低通 / 高通,并手算一两个中间频率。
**不要求**:会画 `|H|` 曲线的所有细节,以及相位响应的推导(对称核相位为 0,先认得)。

#### 过关题

1. `[1,2,1]/4`:`H(0)` 和 `H(π)` 各是多少?低通还是高通?
2. `[1,−1]`:同样的问题。
3. 手算 `[1,2,1]/4` 在 `ω = π/2` 的 `|H|`。
4. 5 点盒式滤波器在哪个频率被完全抹掉?

**答案**(脚本第 6 块):① `H(0)` = 核之和 `(1+2+1)/4 = ` **1**,`H(π)` = 交错和 `(1−2+1)/4 = ` **0**,
所以是**低通**;② `H(0) = 1−1 = ` **0**,`H(π) = 1+1 = ` **2**,**高通**(求差 = 找边缘);
③ `H = e^{−iω}(1+cosω)/2`,模 `(1+0)/2 = 0.5`;④ `ω = 2π/5`。

### 第 7 步:采样与混叠

#### 学什么

- 采样就是每隔 `1/fs` 秒取一个值,把连续信号变成离散序列。
- 因为 `e^{i2πn} = 1`,**频率 f 和 f ± fs 采出来的序列一模一样**。
  这就是混叠。
- **表观频率**(采样后你看到的频率):`f_a = |f − round(f/fs)·fs|`。
- 采样定理(sampling theorem):要无失真恢复,信号里最高频率必须小于 `fs/2`;
  `fs/2` 叫奈奎斯特(Nyquist)频率。

#### 学到什么程度

**会算**:给定 f 和 fs,算出表观频率。**会说**:为什么缩小图像或降采样之前要先低通。
**认得**:sinc 插值恢复公式(知道理想恢复长这样即可)。

#### 过关题

1. fs = 8 kHz 时,5 kHz 的余弦和 3 kHz 的余弦采出来有什么关系?
2. fs = 8 kHz:1000、3000、5000、7000、8000、9000 Hz 的表观频率各是多少?
3. 一张图里有周期 2.22 个像素(0.45 周期/像素)的细条纹,不先模糊就隔点抽样,
   看到的会是什么?

**答案**(脚本第 7 块):
① **一模一样**,最大差 `2.7e-14`;
② `1000, 3000, 3000, 1000, 0, 1000`(五千变三千、七千变一千、八千整个掉到直流);
③ 表观频率落在 **0.10 周期/像素**,周期 **10 个像素**
(`0.45×2 − 1 = −0.1`,取绝对值):原本很细的纹变成了一道粗得多的假纹,这就是摩尔纹。
实测:`N=400` 的条纹峰在 k=180(0.45),抽样成 200 点后峰在 k=20(0.10)。

### 第 8 步:进二维

#### 学什么

- 二维 DFT 就是**先对每一行做一维,再对每一列做一维**(可分离)。
  实测 `fft2` 与「先行后列」最大差 `0.0`。
- **一条条纹对应两个亮点**:4×4 的竖条纹(每行都是 `[1,0,−1,0]`),
  `fft2` 只有 `(0,1)` 和 `(0,3)` 两个点非零,幅值都是 **8 = M·N/2**。
- **直流(DC)**:`F[0,0]` 等于全部像素之和。4×4 纯色(值 5)的 `F[0,0] = 80`;
  `fftshift` 之后它跑到下标 `(2, 2)`,也就是图的正中。
- 二维可分离的核(外积)秩为 1:`[1,2,1]/4` 的外积 3×3 核,秩 = 1,
  所以能「横一遍竖一遍」。

#### 学到什么程度

**会算**:小图(4×4)的 DFT 位置与幅值、DC 的值和位置。
**会说**:一条斜条纹在频谱上的位置如何随方向变化。

#### 过关题

1. 4×4、每行 `[1,0,−1,0]` 的图,频谱哪两个点非零?幅值各多少?
2. 4×4 纯色(值 5),`fft2` 的哪个点非零?值是多少?`fftshift` 后在哪?

**答案**(脚本第 8 块):① `(0,1)` 和 `(0,3)`,各 **8**;
② 只有 `F[0,0] = 80`(`16 × 5`),`fftshift` 后在 **(2,2)**。

### 连续傅里叶变换

### 拉普拉斯变换

#### 学什么

拉普拉斯变换把频率 ω 扩展到复平面 `s = σ + iω`。
它回答的问题是:**连续系统稳不稳定**(看极点在 s 平面的哪一侧)。

#### 学到什么程度

**认得**名字和用途。图像处理里基本不用,
以后做控制或模拟滤波器再补。

### Z 变换

#### 学什么

Z 变换是离散版的拉普拉斯,**当多项式看就行**:

- `[1,2,1]` 对应 `1 + 2z⁻¹ + z⁻²`,可以因式分解成 `(1+z⁻¹)²`
  (脚本第 9 块:系数就是 `[1,1]*[1,1]`,和第 3 步的多项式乘法是同一回事)
- 令 `z = e^{iω}`(单位圆上),它就是频率响应。实测 ω = 0、π/2、π 三点
  `|H| = 1.0000、0.5000、0.0000`,与第 6 步的 `(1+cosω)/2` 完全一致
- `z = −1` 是 `(1+z⁻¹)²` 的**双重零点**(zero),这就是 ω=π 被完全抹掉的原因
- 极点(pole)在单位圆里,系统稳定(递归滤波器 IIR 才需要关心)

#### 学到什么程度

**认得**;**会看**零点和频率响应的对应。做音频的 IIR 滤波器(双二阶 biquad)设计时,
再回来补极点的内容。

### 看拉氏与 Z 之前先补什么

**复变函数只在这一段才真正用到**:主线(第 1~8 步)只要复数和欧拉公式。
拉普拉斯和 Z 变换里有个绕不开的概念叫**收敛域**,它的根在复平面的几何。
先补两样,别的等遇到再说:

1. **复平面上的区域**:`|z| < 1` 是单位圆里面,`|z| > 1` 是圆外面。
2. **等比级数在复数下的收敛条件**:就是热身③,只是把公比 `r` 换成复数 `a/z`,
   条件是 `|a/z| < 1`,也就是 `|z| > |a|`。

脚本第 9 块算了 `Σ (a/z)ⁿ`(a = 0.5):

| z | `a/z` 的模 | 结果 |
| :--- | :--- | :--- |
| 2 | 0.250 | 收敛,前 60 项和 1.3333 = `1/(1−a/z)` |
| 0.6 | 0.833 | 收敛,前 60 项和 5.9999,极限 6.0000 |
| 0.25 | 2.000 | **发散**,前 60 项和已到 `1.2e+18` |
| −i | 0.500 | 收敛,前 60 项和 `0.8000+0.4000i`,与 `1/(1−a/z)` 一致 |

**收敛域就是「使这个级数收敛的 z 的范围」**,它只是等比求和的收敛条件换了个复数写法。

留数定理先不补。看到第 53 集(用拉氏变换解微分方程)时,如果老师用的是部分分式,
就用不上;如果用留数,再回头补也来得及。(这一点我从标题没法确认。)

## 七、卡住了怎么办

| 症状 | 多半是 | 回到哪里 |
| :--- | :--- | :--- |
| DFT 公式里为什么有 `e^{−i…}` | 没把它当「转圈的探针」 | 欧拉公式笔记 + 第 4 步 |
| 手算卷积总是错位 | 翻转和平移搞混了 | 第 3 步:改用多项式乘法验算 |
| 「负频率」是什么 | `cos` 拆成了正转 + 反转两个 | 热身②;欧拉公式笔记 |
| 自己写的 DFT 和 `np.fft` 对不上 | 常见原因:指数符号写反、下标起点不对、逆变换忘了除 N | 第 4 步的五行对照表 |
| 频域滤波后图像边缘卷绕 | 没补零,做成了循环卷积 | 第 5 步 |
| 频谱看起来一团糊 | 没取 `log`,或者泄漏 | 第 5 步 |
| 公式推不动 | 数学块不熟 | `二、数学热身` 对应块 |

## 九、小结

| 问题 | 结论 |
| :--- | :--- |
| 数学要补多少 | 五块:复数、三角、求和、内积换基、积分;**全部只要「会算」** |
| 主线是什么 | LTI 系统碰到转圈的零件,只缩放和转角度,不出新零件 |
| 先学连续还是离散 | **先离散**,图像处理只用得上离散 |
| 拉普拉斯、Z 变换要学吗 | 图像处理用不上;当多项式看一眼,主线走通后补 |
| 怎么推进 | 每步先做过关题,答不对回到这一步;进度由题目决定,不由日历决定 |
| 过关题答案哪来 | [`31_signals_roadmap.py`](../../Python-Prototyping/Ch04_Frequency_Domain/31_signals_roadmap.py) 跑出来的,不是凭感觉写的 |
