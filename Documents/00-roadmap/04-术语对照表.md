中文教材的译名并不统一 —— 同一个 unsharp masking,有的书叫「反锐化掩模」,
有的叫「钝化掩蔽」,有的干脆叫「USM 锐化」。**记英文比记中文可靠**,
因为英文只有一个。

下面按主题分组,每个词都给出**正文里第一次出现的那一篇**,方便回去看上下文。

## 一、最容易混的五组

这五组不是「不知道」,而是**知道但容易搞反**,单独拎出来:

| 中文 | English | 一句话区别 |
| :--- | :--- | :--- |
| 相关 | **correlation** | 核直接盖上去。`cv2.filter2D` 实际做的是这个 |
| 卷积 | **convolution** | 核先转 180° 再盖。教材讲的是这个 |
| | | |
| 亮度(物理) | **luminance** | 真实光强,和光子数成正比 |
| 亮度(编码域) | **luma** `Y′` | 对编码值加权得到的近似,视频里的 Y 是它 |
| 明度(感知) | **lightness** `L*` | 人眼**觉得**多亮,Lab 里的 L |
| | | |
| 直方图均衡化 | **histogram equalization** | 目标分布固定是均匀 |
| 直方图规定化 / 匹配 | **histogram specification / matching** | 目标分布由你给 |
| | | |
| 正向映射 | **forward mapping** | 遍历源图往外投,会留空洞 |
| 反向映射 | **backward / inverse mapping** | 遍历目标往回取,不留空洞 |
| | | |
| 饱和 | **saturate / clamp** | 越界夹到边界(255 就是 255) |
| 回绕 | **wrap-around / modulo** | 越界取模(300 变成 44) |

## 附:几个译名不统一的坑

| English | 见过的中文译法 | 建议 |
| :--- | :--- | :--- |
| unsharp masking | 反锐化掩模 / 钝化蒙版 / 钝化掩蔽 / USM 锐化 | **记 USM**,中文随便哪个都行 |
| kernel | 核 / 卷积核 / 掩模 / 模板 / 算子 | 都指同一个东西 |
| mask | 掩模 / 蒙版 / 掩码 | 注意它还有「二值选区」的意思,看上下文 |
| intensity | 强度 / 亮度 / 灰度 | Gonzalez 书里 intensity 就是灰度值 |
| luminance vs luma | 都译成「亮度」 | **中文区分不开,必须看英文** —— 见第一节 |
| bin | 桶 / 箱 / 区间 | 直方图的那 256 个格子 |
| clip | 裁切 / 削顶 / 限幅 | 摄影里说「过曝削顶」,代码里说「限幅」 |
