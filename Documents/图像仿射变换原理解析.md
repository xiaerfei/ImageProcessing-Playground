## 1. 总览

**仿射变换（Affine Transform）** 是一类保持"平行性"的几何变换：直线变换后仍是直线，
平行线变换后仍平行。2D 仿射变换可以拆解为六种原子操作的组合：

| 原子操作 | 数学本质 | 效果 |
|---------|---------|------|
| 平移 Translation | 坐标加法 | 整体移动 |
| 缩放 Scale | 坐标乘法 | 放大/缩小 |
| 旋转 Rotation | 正交矩阵 | 绕点转动 |
| 转置 Transpose | x/y 互换 | 沿主对角线翻转 |
| 镜像 Mirror | 负缩放 | 水平/垂直翻转 |
| 剪切 Shear（本文未用） | 交叉项 | 错切变形 |

整个变换模块解决三个工程问题：

1. **如何把一串变换合并成一个矩阵** → 3×3 齐次坐标（第 2 章）；
2. **如何让旋转/缩放绕图像中心而不是左上角** → 三明治夹层法（第 4 章）；
3. **变换后的像素从哪里来** → 反向映射 + 插值采样（第 5 章）。

一个完整的几何变换流水线是：

```
参数 → 复合正向矩阵 M → (Fit 模式算新画布) → 检查可逆 → 求 M⁻¹
    → 遍历目标画布每像素 → M⁻¹ 反推源坐标 → 插值采样 → 输出图
```

## 2. 数学基础

### 2.1 为什么是 3×3 齐次矩阵

**问题**：2×2 矩阵只能表达"绕原点的线性变换"（旋转/缩放/剪切/翻转），
**平移无法表示成矩阵乘法**——因为平移是加法 `x' = x + tx`，而线性变换只能是
`x' = a·x + b·y` 的形式，常数项没有安放之处。

**解法**：给每个点追加一个恒为 1 的第三分量，升到**齐次坐标**：

$$
\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix}
=
\begin{bmatrix} 1 & 0 & tx \\ 0 & 1 & ty \\ 0 & 0 & 1 \end{bmatrix}
\begin{bmatrix} x \\ y \\ 1 \end{bmatrix}
=
\begin{bmatrix} x + tx \\ y + ty \\ 1 \end{bmatrix}
$$

平移量进入了矩阵的第三列，"加法"变成了"乘法"。由此获得三个关键能力：

1. **统一表示**：平移/缩放/旋转全部是 3×3 矩阵，一个 `simd_double3x3` 类型通吃；
2. **预复合**：任意多步变换可以预先连乘成**一个**矩阵 M，每像素只做一次
   矩阵×向量（9 次乘 6 次加），而不是每步各算一遍；
3. **统一求逆**：反向映射只需要对 M 求一次逆 `simd_inverse(M)`，
   不用为每种组合手工推逆公式。

> **坑点 1**：有人会问"用 2×3 矩阵（仿射矩阵的另一种写法）不是更省吗？"
> 2×3 写法 `[a b tx; c d ty]` 确实等价且省一个分量，但它**不可逆**——
> 齐次 3×3 的第三行 `[0 0 1]` 保证了 det ≠ 0 的结构，并且向上兼容透视变换
> （第三行改成 `[p q 1]` 即可），simd/Metal 的 API 也都按 3×3/4×4 方阵设计。

### 2.2 列向量右乘与"从右往左"的施加顺序

本实现采用**列向量右乘**约定：

$$
v' = M \cdot v, \qquad M = M_n \cdots M_2 M_1
$$

复合矩阵作用在向量上时，**最右边的矩阵最先作用于 v**，最左边的最后作用。
所以读复合矩阵要**从右往左读**，那才是像素经历的真实顺序。

代码里的复合模式是"不断左乘新矩阵"：

```objc
simd_double3x3 M = IAMatrixTranslation(-cx, -cy);      // ① 最先施加
M = simd_mul(IAMatrixScale(sx, sy), M);                // ② 第二施加
M = simd_mul(IAMatrixRotation(deg), M);                // ③ 第三施加
M = simd_mul(IAMatrixTranslation(cx+tx, cy+ty), M);    // ④ 最后施加
```

每行 `simd_mul(A, M)` 的含义是 `M ← A·M`：**新矩阵 A 排到变换链的最左端，
也就是最后作用于像素**。最终 `M = ④·③·②·①`。

> **坑点 2（最高频错误）**：把"代码书写顺序"当成"施加顺序"。
> `M = ④·③·②·①`，写代码的顺序（①②③④）恰好与施加顺序**相反**。
> 想验证顺序的影响，可打开 `TransformOrderPlayground.html`：
> 同一组 T/R/S 变换，`T·R·S` 与 `S·R·T` 的结果完全不同。

**顺序敏感性（交换律）速查**——矩阵乘法不满足交换律，但也不是两两都敏感：

| 组合 | 是否可交换 | 原因 |
|------|-----------|------|
| T 与 R | ❌ 不可交换 | R 会把平移方向一起转走 |
| T 与 S | ❌ 不可交换 | S 会把平移量一起放大/缩小 |
| R 与**均匀**缩放 S(k,k) | ✅ 可交换 | R·S(k,k) = S(k,k)·R，图像重合 |
| R 与**非均匀**缩放 S(sx≠sy) | ❌ 不可交换 | 先旋转再拉伸 ≠ 先拉伸再旋转 |
| F（镜像）与 T | ❌ 不可交换 | 镜像把位移方向也镜像了 |
| F 与 R | ❌ 不可交换 | 除非 180° 等特殊角度 |
| T 与 T | ✅ | 加法交换 |
| S 与 S | ✅ | 乘法交换 |

工程含义：**均匀缩放 + 旋转**的顺序无所谓，但**只要涉及平移或非均匀缩放，
顺序就是语义的一部分**，必须固定并写进注释（本实现固定为
"缩放 → 转置 → 镜像 → 旋转 → 平移"）。

### 2.3 位图坐标系：y 轴向下

数学课本的直角坐标系 y 轴**向上**；位图/屏幕坐标系 y 轴**向下**（原点在左上角）。
这一个符号差异会连锁产生两个现象：

1. **旋转方向反转**：标准旋转矩阵
   $$
   R(\theta)=\begin{bmatrix}\cos\theta & -\sin\theta & 0\\ \sin\theta & \cos\theta & 0\\ 0&0&1\end{bmatrix}
   $$
   在数学坐标系里是**逆时针**；代入 y 向下的位图坐标后，视觉上变成**顺时针**。
   所以 `IAMatrixRotation(90)` 在屏幕上看是顺时针转 90°——正角度 = 屏幕顺时针。

2. **手性翻转类变换**：镜像/转置的"翻转轴"位置不受影响，但与旋转组合时，
   旋转方向的直觉（逆/顺时针）必须按 y 向下重新校准。

> **坑点 3**：从数学库或教学材料抄来的旋转矩阵，如果测试发现"方向反了"，
> 不是矩阵错了，而是坐标系约定不同。统一约定即可，不要"顺手"把矩阵改成
> 逆时针版本——那会让所有与 Metal/shader 共享的矩阵全部对不上。

## 3. 基础变换矩阵

以下五个构造器是整个模块的"字汇表"。全部以**坐标系原点 (0,0) 为基准**——
这句话的含义在第 4 章展开。

### 3.1 平移 T(tx, ty)

$$
\begin{bmatrix} 1 & 0 & tx \\ 0 & 1 & ty \\ 0 & 0 & 1 \end{bmatrix}
\begin{bmatrix} x \\ y \\ 1 \end{bmatrix}
=
\begin{bmatrix} x+tx \\ y+ty \\ 1 \end{bmatrix}
, \qquad \det = 1
$$

平移量住在齐次第三列。不改变面积与方向。

### 3.2 缩放 S(sx, sy)

$$
\begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix}
, \qquad \det = s_x \cdot s_y
$$

- **不动点是原点**：放大时图像向右下"撑大"，左上角纹丝不动；
- sx·sy < 0 时手性翻转（镜像）；sx·sy = 0 时**退化**（见 3.6）；
- 后面会看到：经过夹层后，实际效果是**以图像中心缩放**。

### 3.3 旋转 R(θ)

$$
\begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}
, \qquad \det = 1
$$

纯旋转不改变面积（det=1），列向量保持单位正交。角度制入参内部转弧度。

### 3.4 转置 Tr

$$
\begin{bmatrix} 0 & 1 & 0 \\ 1 & 0 & 0 \\ 0 & 0 & 1 \end{bmatrix}
, \qquad \det = -1
$$

作用是交换 x 与 y（x'=y, y'=x）：单独使用时图像沿 **y = x 对角线**镜像。
连续做两次回到原图（Tr·Tr = I）。det 为负说明它是"翻转类"变换——
改变手性（顺时针的箭头转置后变逆时针）。

### 3.5 镜像 F：负数缩放就是翻转

镜像的处理方式非常巧妙：**没有单独写一个复杂矩阵函数，而是直接借用缩放矩阵，
传入负数（`-1.0`）来实现**。

#### (a) 为什么"负数缩放"就是镜像？

缩放矩阵的对角线元素是各方向的缩放比例：

- `scaleX = 2.0`：X 方向放大 2 倍；
- `scaleX = 1.0`：不变；
- `scaleX = -1.0`：任何点的横坐标 $x$ 乘以 $-1$ 变成 $-x$——
  **右边的点跑到左边，左边的点跑到右边，这就是标准的水平翻转**。

同理 `scaleY = -1.0` 实现垂直翻转（上下镜像）。代码中的逻辑正是如此：

```objc
double mx = params.mirrorHorizontal ? -1.0 : 1.0;   // 水平镜像: sx = -1
double my = params.mirrorVertical   ? -1.0 : 1.0;   // 垂直镜像: sy = -1
if (mx < 0.0 || my < 0.0) {
    M = simd_mul(IAMatrixScale(mx, my), M);
}
```

- 水平镜像（sx=-1）：单独使用绕 **y 轴（x=0）** 翻 → 夹层后绕图像**垂直中轴线**翻；
- 垂直镜像（sy=-1）：单独使用绕 **x 轴（y=0）** 翻 → 夹层后绕图像**水平中轴线**翻。

#### (b) 镜像也是"以中心为轴"的吗？

是的，依然得益于第 4 章的三明治复合顺序。如果不把图像平移到原点，
直接对图像乘 `scaleX = -1`：纯缩放以坐标系原点 $(0,0)$（画布左上角）为基准，
图像会整体翻转到画布**左侧负坐标区域**，"飞出屏幕"消失。

而在复合流水线中（从右往左读）：

1. **先平移**：图像中心被移动到原点 $(0,0)$；
2. **再镜像**：执行 `IAMatrixScale(-1, 1)`。此时图像中心正好踩在原点上，
   翻转表现为**绕自己的中心中轴线左右翻转**；
3. **后平移**：中心移回画布中央。

最终效果：**图像在原地左右（或上下）对称翻转，稳稳留在画布中央。**

#### (c) 镜像会影响逆矩阵（反向映射）吗？

不需要为镜像做任何特殊处理：

- 缩放矩阵的行列式 = $scaleX \times scaleY$；水平镜像的 det = $(-1)\times 1 = -1$。
  只要 **det ≠ 0 就完全可逆**——负号只代表"翻转手性"，不影响可逆性；
- 更妙的是：**纯镜像矩阵的逆矩阵就是它自己**（镜像过一次的图像再镜像一次
  就还原了，$F \cdot F = I$）；
- 与旋转、平移复合后，`simd_inverse` 会自动把镜像的影响正确包含进逆矩阵，
  反向映射采样时一切都在线代公式中自动搞定。

#### (d) 组合拳：水平 + 垂直镜像同时开启

`mirrorHorizontal = YES` 且 `mirrorVertical = YES` 时，$m_x = m_y = -1$，
相当于 `IAMatrixScale(-1, -1)`：

$$
\begin{bmatrix} -1 & 0 \\ 0 & -1 \end{bmatrix}
= R(180^\circ)
$$

数学上等价于**中心对称（旋转 180°）**，图像同时左右 + 上下翻转。
这也是镜像与旋转唯一可交换的特殊情形（见 2.2 交换律速查表）。

### 3.6 行列式与可逆性：不是任何矩阵都能求逆

矩阵可逆的硬性条件：**方阵** 且 **行列式 ≠ 0**（非奇异）。

| 矩阵 | det | 可逆？ |
|------|-----|-------|
| 平移/旋转 | 1 | ✅ |
| 缩放(1.25, 1.25) | 1.5625 | ✅ |
| 镜像/转置 | -1 | ✅（det 为负只是"翻转"，不影响可逆） |
| 缩放(0, sy) | **0** | ❌ **奇异** |

**为什么 det=0 就不可逆**：以 `scaleX = 0` 为例，整张 2D 图像被压成一条
毫无厚度的直线——原本不同位置的像素被挤压**重叠到同一个点**。信息已经丢失，
不可能通过逆矩阵把直线"无中生有地撑回"2D 图像。反映在数值上就是：
两点不同源坐标映射到同一点，逆映射是多值的，函数都不成立，谈不上矩阵逆。

> **坑点 4**：`simd_inverse` 对奇异矩阵不会崩溃，而是产出 inf/nan 垃圾。
> 必须在求逆**之前**用 `simd_determinant` 拦截：
>
> ```objc
> if (fabs(simd_determinant(forward)) < 1e-12) { return nil; }
> simd_double3x3 inverse = simd_inverse(forward);
> ```
>
> 阈值取 `1e-12` 而不是 `== 0`：浮点连乘后 det 很少精确为 0，
> 但接近 0 的矩阵求逆会产生天文数字级的坐标，采样结果同样是乱码。

## 4. 复合变换：三明治夹层法

### 4.1 原点基准问题：为什么会"飞出画布"

第 3 章的所有矩阵都以**坐标系原点 (0,0)** 为基准，而位图的原点在**左上角**。
直接把旋转矩阵乘到像素上会发生什么？——图像绕**左上角**转：

- 旋转 30°：大半个画面转出画布左/上方；
- 放大 1.5×：图像向右下方撑大，左上角不动；
- 水平镜像：整幅图翻到 x 轴左侧（负坐标区域）。

用户体验上期待的却是"图像在原地转、原地缩放、原地翻"——即**以图像几何中心为锚点**。

### 4.2 三明治夹层法

解法是经典的复合变换套路：**把中心搬到原点 → 变换 → 搬回去**。

$$
M = \underbrace{T(cx+\tau_x,\, cy+\tau_y)}_{\text{搬回+平移}} \cdot
    \underbrace{R \cdot F \cdot T_r \cdot S}_{\text{核心变换(原点基准)}} \cdot
    \underbrace{T(-cx,\, -cy)}_{\text{搬到原点}}
$$

从右往左读，每个像素经历：

1. `T(-cx,-cy)`：图像几何中心被平移到坐标系原点；
2. `S → Tr → F → R`：此时**中心与原点重合**，这些"原点基准"的算子
   全部自动表现为**绕图像中心**操作——缩放原地缩放、旋转原地转、
   镜像绕中轴线翻；
3. `T(cx+tx, cy+ty)`：中心搬回原位，并顺便叠加用户指定的平移量 tx/ty。

对应实现（注意每行都是**左乘**，与上面公式从左到右一一对应）：

```objc
+ (simd_double3x3)matrixWithParams:(IATransformParams)params imageSize:(NSSize)size {
    double cx = (size.width  - 1.0) * 0.5;
    double cy = (size.height - 1.0) * 0.5;

    simd_double3x3 M = IAMatrixTranslation(-cx, -cy);                  // ① 搬到原点(最先施加)
    M = simd_mul(IAMatrixScale(params.scaleX, params.scaleY), M);      // ② 缩放
    if (params.transpose) {
        M = simd_mul(IAMatrixTranspose2D(), M);                        // ③ 转置(可选)
    }
    double mx = params.mirrorHorizontal ? -1.0 : 1.0;
    double my = params.mirrorVertical   ? -1.0 : 1.0;
    if (mx < 0.0 || my < 0.0) {
        M = simd_mul(IAMatrixScale(mx, my), M);                        // ④ 镜像(可选)
    }
    M = simd_mul(IAMatrixRotation(params.rotationDegrees), M);         // ⑤ 旋转
    M = simd_mul(IAMatrixTranslation(cx + params.translateX,
                                     cy + params.translateY), M);      // ⑥ 搬回+平移(最后施加)
    return M;
}
```

两个工程细节：

- **可选项跳过**：transpose/镜像未启用时不左乘单位矩阵，省两次 3×3 乘法；
- **顺序是语义**：②→⑤ 的次序一旦改变，非均匀缩放 + 旋转的结果就不同
  （见 2.2 的交换律表）。这个顺序必须像 API 契约一样固定下来。

### 4.3 为什么中心是 `(width-1)/2` 而不是 `width/2`

像素是**离散网格**：宽 2 的图像，像素索引只有 0 和 1，不存在"第 2 列"。

| 图像宽 | `width/2` | `(width-1)/2` | 网格真实中点 |
|-------|-----------|---------------|-------------|
| 2 | 1.0（落在像素 1 的右边界）| 0.5（像素 0 与 1 的正中间）| 0.5 |
| 3 | 1.5（两像素之间空隙）| 1.0（**精确落在中间像素**上）| 1.0 |
| 128 | 64.0 | 63.5 | 63.5 |

用 `width/2` 会让旋转/缩放的轴心系统性偏移半个像素——宏观表现为旋转后图像
"略微发飘"、缩放后边缘多/少半像素的裁切。`(width-1)/2` 保证锚点是
**像素网格真正的物理几何中心**。

> **坑点 5**：这是"数学坐标"与"像素索引"混用时的经典 off-by-half 错误。
> 同理，双线性插值判断越界时用的是 `w - 0.5`（见 5.5），都是同一套
> "像素中心在整数点、像素边界在半整数点"的语义。

## 5. 重采样：反向映射与插值

有了矩阵 M，还剩最后一个问题：**目标画布上每个像素的颜色从哪来？**
这就是重采样（resampling），它分两步：先定位（反向映射），再取色（插值）。

### 5.1 正向映射 vs 反向映射：为什么必须反过来

**正向映射**（splatting）：遍历源图像素，用 M 把每个源像素投到目标画布。

- ❌ **放大时出现空洞**：放大 2× 时，1 个源像素按坐标映射后只能"占位"
  目标画布上的 1 个点，而它理论覆盖 2×2=4 个像素——其余 3 个没人写，成洞；
- ❌ 缩小时多个源像素挤到同一目标点，还要额外处理冲突（累加/取最值？）。

**反向映射**（inverse mapping / backward mapping）：遍历**目标**画布每个像素，
反过来问：**"这个空白像素，应该从源图的哪个位置'偷'颜色？"**

$$
P_{\text{source}} = M^{-1} \cdot P_{\text{target}}
$$

推导只需一步：正向关系是 `P_target = M · P_source`，两边左乘 M⁻¹，
利用 `M⁻¹·M = I` 即得。每个目标像素都有唯一答案 → **画布必然被填满，零空洞**。

```objc
// 逆矩阵只求一次(循环外),循环内每像素只做一次 3×3 矩阵×向量
if (fabs(simd_determinant(forward)) < 1e-12) { return nil; }  // 先拦奇异矩阵
simd_double3x3 inverse = simd_inverse(forward);

for (NSInteger yd = 0; yd < dh; yd++) {
    for (NSInteger xd = 0; xd < dw; xd++) {
        simd_double3 ps = simd_mul(inverse, (simd_double3){
            (double)xd + offsetX, (double)yd + offsetY, 1.0 });
        ... // 齐次归一化 → 采样
    }
}
```

> **坑点 6**：反向映射中的 `xd + offsetX` 极易漏写。offset 只在 Fit 模式
> （第 6 章）非零，KeepSize 模式下为 0，测试时不容易暴露——一旦开启 Fit
> 且旋转出画，结果就会整体错位一个包围盒的距离。

### 5.2 齐次归一化（Perspective Division）

反推得到的 `ps` 是三维齐次向量，需要除以 w 分量转回 2D：

```objc
double wgt = (fabs(ps.z) < 1e-12) ? 1.0 : ps.z;   // 防 0 除
double sx = ps.x / wgt;
double sy = ps.y / wgt;
```

- **仿射变换**下 z 恒等于 1，这两行除法是"空操作"；
- 但把第三行改成 `[p q 1]` 即可支持**透视变换**，那时 z 不再是 1，
  必须归一化才能得到正确的平面坐标。

> **坑点 7**：这是为透视预留的通用性。如果确定永远只做仿射，可以省掉；
> 但省掉后将来升级透视时，错误会以"图像轻微变形"的形式出现，很难排查。
> 建议保留（代价可忽略）。

### 5.3 反推坐标是浮点数 → 必须插值

`M⁻¹` 里含 cos/sin/缩放倒数，反推出来的源坐标通常是 `10.34, 25.82` 这样的
浮点值，而像素只存在于整数网格上。"非整数位置取什么颜色"由插值策略决定。

### 5.4 最近邻插值 `IASampleNearest`

**策略**：谁离我最近就抄谁，绝不混合。

```objc
static inline void IASampleNearest(const uint8_t *src, NSInteger w, NSInteger h,
                                   double x, double y, uint8_t out[4]) {
    // ① 四舍五入:锁定最近的整数像素(5.7→6, 12.2→12)
    NSInteger sx = (NSInteger)lround(x);
    NSInteger sy = (NSInteger)lround(y);
    // ② 越界判定:图像外 = 全透明(而非黑)
    if (sx < 0 || sx >= w || sy < 0 || sy >= h) {
        out[0] = out[1] = out[2] = out[3] = 0;
        return;
    }
    // ③ 2D→1D 寻址:跳过 sy 整行(sy*w),行内走 sx 个像素,每像素 4 字节
    const uint8_t *p = src + (sy * w + sx) * 4;
    out[0] = p[0]; out[1] = p[1]; out[2] = p[2]; out[3] = p[3];
}
```

- **优点**：零乘法、零权重计算，最快；
- **缺点**：放大/旋转时产生马赛克锯齿（最近邻阶梯）；
- **注意**：与双线性不同，最近邻**不做边缘 clamp**——四舍五入后越界就直接
  透明。两种插值在边缘半像素处的行为差异是设计选择，不是 bug。

> **坑点 8**：`sy * w + sx` 中的 `w` 必须是**源图宽度**。若误传目标宽度，
> 在 Fit 模式（目标 ≠ 源尺寸）下整幅图会按错误行距"错位读取"，出现斜向
> 撕裂的花屏。

### 5.5 双线性插值 `IASampleBilinear`

**策略**：反推坐标落在 4 个相邻像素围成的 1×1 格子内，按"距离反比"对
4 个邻居做加权平均。离谁近，谁的话语权大。

#### (a) 从 Lerp 推导权重公式

线性插值（Lerp）最直觉的形式是"起点 + 路程比例 × 总差距"：

$$
p_{00} + (p_{10}-p_{00})\cdot dx \;=\; (1-dx)\cdot p_{00} + dx\cdot p_{10}
$$

相邻像素网格间距恒为 1（分母 `x1-x0 = 1` 被消掉），所以比例就是距离本身。
双线性 = **先横着 Lerp 一次，再竖着 Lerp 一次**：

$$
V_{\text{top}} = (1-dx)p_{00} + dx\cdot p_{10}
\qquad
V_{\text{bottom}} = (1-dx)p_{01} + dx\cdot p_{11}
$$

$$
V_{\text{final}} = (1-dy)\,V_{\text{top}} + dy\,V_{\text{bottom}}
$$

展开合并、按像素归项，就得到代码里的 4 个权重：

$$
\begin{aligned}
w_{00} &= (1-dx)(1-dy) & w_{10} &= dx\,(1-dy)\\
w_{01} &= (1-dx)\,dy   & w_{11} &= dx\,dy
\end{aligned}
\qquad
w_{00}+w_{10}+w_{01}+w_{11} = 1
$$

**几何解释**：目标点把 1×1 格子切成 4 块矩形，每个邻居的权重等于它
**对角方向那块矩形的面积**——所以"明明 dx 是离左边的距离"，算左上角权重
用的却是 `(1-dx)`：它其实是**到右边的距离**，离右边越远，左边分得的蛋糕越大。

`dx` 的精确定义：从**左邻居 x0 = floor(x)** 到目标点 x 的横向距离，恒在 [0,1)。
（例：x = 5.3 → x0 = 5，dx = 0.3；到右邻居 x1 = 6 的距离是 1 - 0.3 = 0.7。）

#### (b) 完整实现

```objc
static inline void IASampleBilinear(const uint8_t *src, NSInteger w, NSInteger h,
                                    double x, double y, uint8_t out[4]) {
    // ① 粗筛越界:像素中心语义,合法范围 [-0.5, w-0.5]
    if (x < -0.5 || x > (double)w - 0.5 || y < -0.5 || y > (double)h - 0.5) {
        out[0] = out[1] = out[2] = out[3] = 0;
        return;
    }
    // ② 定位左上邻居 + 小数偏移
    NSInteger x0 = (NSInteger)floor(x);
    NSInteger y0 = (NSInteger)floor(y);
    double dx = x - (double)x0;          // [0,1):左邻居 → 目标点的距离
    double dy = y - (double)y0;
    NSInteger x1 = x0 + 1, y1 = y0 + 1;
    // ③ 边缘 clamp:越界邻居被拉回边界,与内侧点重合
    if (x0 < 0) { x0 = 0; }  if (x0 > w - 1) { x0 = w - 1; }
    if (y0 < 0) { y0 = 0; }  if (y0 > h - 1) { y0 = h - 1; }
    if (x1 < 0) { x1 = 0; }  if (x1 > w - 1) { x1 = w - 1; }
    if (y1 < 0) { y1 = 0; }  if (y1 > h - 1) { y1 = h - 1; }
    // ④ 4 个邻居的地址
    const uint8_t *p00 = src + (y0 * w + x0) * 4;
    const uint8_t *p10 = src + (y0 * w + x1) * 4;
    const uint8_t *p01 = src + (y1 * w + x0) * 4;
    const uint8_t *p11 = src + (y1 * w + x1) * 4;
    // ⑤ 面积权重
    double w00 = (1.0 - dx) * (1.0 - dy);
    double w10 = dx         * (1.0 - dy);
    double w01 = (1.0 - dx) * dy;
    double w11 = dx         * dy;
    // ⑥ 四通道加权混合 + 限幅 + 四舍五入
    for (int c = 0; c < 4; c++) {
        double v = w00 * p00[c] + w10 * p10[c] + w01 * p01[c] + w11 * p11[c];
        out[c] = (uint8_t)lround(fmin(fmax(v, 0.0), 255.0));
    }
}
```

#### (c) 边缘 clamp：为什么不能"一刀切"

设 `w = 10`（合法索引 0…9），反推坐标 `x = 9.2`：

- `x0 = floor(9.2) = 9` ✅ 合法；
- `x1 = x0 + 1 = 10` ❌ **越界**！直接取址会读到图像外的垃圾内存，甚至崩溃。

传统粗暴写法是"`x >= w-1` 就整个判越界返回透明"——后果是**最右一列、
最下一行像素被整条裁掉**，缩放/旋转结果的边缘出现一圈透明缝隙。

本实现的 clamp 是"边界吸附"：`x1` 被拉回 9，与 `x0` 重合。
公式照常运转（重合点的权重无论多大都只贡献同一颜色），既绝对安全，
又把边缘像素完整保留下来。

> **坑点 9**：粗筛用 `w - 0.5` 而不是 `w - 1`。像素中心在整数点，
> `x = w - 0.6` 的目标点虽然"超出最后一个像素中心"，但它的插值格子仍有
> 一半压在图内，clamp 后仍能给出有意义的颜色；只有超过半个像素才算真出界。

> **坑点 10**：`fmax/fmin` 限幅不是多余。权重和恒为 1 时结果理论上必在
> [0,255]，但浮点误差会产出 `-0.00001` 或 `255.00001`，直接强转 `uint8_t`
> 属于未定义行为。顺序是：先 `fmax(…, 0)`、再 `fmin(…, 255)`、最后 `lround`
> 四舍五入。

## 6. 自适应画布（CanvasModeFit）

旋转 30° 后图像会伸出原画布。`IACanvasModeKeepSize` 保持原尺寸、
转出部分被裁掉；`IACanvasModeFit` 则自动扩展画布到**刚好容纳**变换后的四角。

### 6.1 算法：四角包围盒

一个矩形的仿射像仍是矩形（仿射保持平行性），所以只需把**4 个角点**用正向
矩阵 M 推过去，取 min/max 包围盒：

```objc
double cornerX[4] = {0.0, (double)sw - 1.0, 0.0,             (double)sw - 1.0};
double cornerY[4] = {0.0, 0.0,              (double)sh - 1.0, (double)sh - 1.0};
for (int i = 0; i < 4; i++) {
    simd_double3 p = simd_mul(forward, (simd_double3){cornerX[i], cornerY[i], 1.0});
    double wgt = (fabs(p.z) < 1e-12) ? 1.0 : p.z;   // 齐次归一化(为透视预留)
    xs[i] = p.x / wgt;  ys[i] = p.y / wgt;
}
// 包围盒 → 新画布尺寸 + 偏移
dw = (NSInteger)ceil(maxX - minX) + 1;
dh = (NSInteger)ceil(maxY - minY) + 1;
offsetX = minX;   // 通常为负:转出画布的部分
offsetY = minY;
```

三个要点：

1. **为什么用角点而不是逐像素**：矩形的像仍是矩形（凸包即四角连线），
   4 次矩阵乘法就够，不必对全部像素做正向投射；
2. **offsetX/offsetY 的含义**：包围盒左上角通常落在负坐标（图像转出了
   原画布）。新画布从 (0,0) 开始编号，因此目标像素 `(xd, yd)` 对应的
   **世界坐标**是 `(xd+offsetX, yd+offsetY)`——反向映射时必须加回去
   （见坑点 6）；
3. **`+1` 与 `ceil`**：包围盒宽度是浮点（如 121.4），像素数要向上取整再 +1
   才能同时容纳两端点（点数 = 跨度 + 1）。

### 6.2 内存防线

```objc
const NSInteger kMaxSide = 8192;   // 防止缩放调得过大把内存吃光
if (dw <= 0 || dh <= 0 || dw > kMaxSide || dh > kMaxSide) { return nil; }
```

一张 8192×8192 的 RGBA 图 = 268 MB。用户把缩放调到 100× 时，没有这道闸
应用会直接被 jetsam 杀掉。失败统一返回 nil，由调用方决定 UI 呈现。

## 8. 完整参考实现

以下是 `ImageAlgorithm/ImageAlgorithm/Algorithm/IAAffineTransform.m` 的
完整内容（详细注释版）。头文件 `IAAffineTransform.h` 声明了矩阵构造器、
`IATransformParams` 参数结构（含 translateX/Y、rotationDegrees、scaleX/Y、
mirrorHorizontal/Vertical、transpose）、`IAInterpolation`（最近邻/双线性）与
`IACanvasMode`（KeepSize/Fit）两枚举，以及 `IAImageBuffer`（RGBA8888
像素缓冲，`width/height/data` 三成员）。

```objc
//
//  IAAffineTransform.m
//  ImageAlgorithm
//
//  3x3 齐次矩阵 + 反向映射(Backward Mapping)的通用几何变换。
//

#import "IAAffineTransform.h"

#pragma mark - 矩阵构造

// simd_matrix_from_rows 允许按课本的行布局书写,内部虽是列主序但对调用方透明。

/// 平移矩阵:x' = x + tx, y' = y + ty(平移量住在齐次第三列)
simd_double3x3 IAMatrixTranslation(double tx, double ty) {
    return simd_matrix_from_rows((simd_double3){1.0, 0.0, tx},
                                 (simd_double3){0.0, 1.0, ty},
                                 (simd_double3){0.0, 0.0, 1.0});
}

/// 缩放矩阵:det = sx·sy;取负值即镜像;sx·sy=0 时退化不可逆
simd_double3x3 IAMatrixScale(double sx, double sy) {
    return simd_matrix_from_rows((simd_double3){ sx, 0.0, 0.0},
                                 (simd_double3){0.0,  sy, 0.0},
                                 (simd_double3){0.0, 0.0, 1.0});
}

/// 旋转矩阵:数学坐标系里逆时针,位图 y 轴向下 → 屏幕视觉为顺时针
simd_double3x3 IAMatrixRotation(double degrees) {
    double rad = degrees * M_PI / 180.0;
    double c = cos(rad), s = sin(rad);
    return simd_matrix_from_rows((simd_double3){  c,  -s, 0.0},
                                 (simd_double3){  s,   c, 0.0},
                                 (simd_double3){0.0, 0.0, 1.0});
}

/// 转置:x' = y, y' = x;沿主对角线翻转;det = -1;连续两次回到原图
simd_double3x3 IAMatrixTranspose2D(void) {
    return simd_matrix_from_rows((simd_double3){0.0, 1.0, 0.0},
                                 (simd_double3){1.0, 0.0, 0.0},
                                 (simd_double3){0.0, 0.0, 1.0});
}

/// 默认参数 = 恒等变换(scale 中性值是 1 不是 0)
IATransformParams IATransformParamsDefault(void) {
    return (IATransformParams){
        .translateX = 0.0, .translateY = 0.0,
        .rotationDegrees = 0.0,
        .scaleX = 1.0, .scaleY = 1.0,
        .mirrorHorizontal = NO, .mirrorVertical = NO, .transpose = NO,
    };
}

#pragma mark - 采样

/// 最近邻:lround 四舍五入 → 越界透明 → 指针寻址直拷 RGBA
static inline void IASampleNearest(const uint8_t *src, NSInteger w, NSInteger h,
                                   double x, double y, uint8_t out[4]) {
    NSInteger sx = (NSInteger)lround(x);
    NSInteger sy = (NSInteger)lround(y);
    if (sx < 0 || sx >= w || sy < 0 || sy >= h) {
        out[0] = out[1] = out[2] = out[3] = 0;
        return;
    }
    const uint8_t *p = src + (sy * w + sx) * 4;
    out[0] = p[0]; out[1] = p[1]; out[2] = p[2]; out[3] = p[3];
}

/// 双线性:4 邻居面积权重(两次 Lerp 展开),边缘 clamp 保留末行/列
static inline void IASampleBilinear(const uint8_t *src, NSInteger w, NSInteger h,
                                    double x, double y, uint8_t out[4]) {
    // 粗筛越界:像素中心语义 [-0.5, w-0.5]
    if (x < -0.5 || x > (double)w - 0.5 || y < -0.5 || y > (double)h - 0.5) {
        out[0] = out[1] = out[2] = out[3] = 0;
        return;
    }
    NSInteger x0 = (NSInteger)floor(x);
    NSInteger y0 = (NSInteger)floor(y);
    double dx = x - (double)x0;          // 左邻居 → 目标点的距离,[0,1)
    double dy = y - (double)y0;
    NSInteger x1 = x0 + 1, y1 = y0 + 1;
    // 边缘 clamp:越界邻居拉回边界与内侧点重合,保留边缘像素
    if (x0 < 0) { x0 = 0; }  if (x0 > w - 1) { x0 = w - 1; }
    if (y0 < 0) { y0 = 0; }  if (y0 > h - 1) { y0 = h - 1; }
    if (x1 < 0) { x1 = 0; }  if (x1 > w - 1) { x1 = w - 1; }
    if (y1 < 0) { y1 = 0; }  if (y1 > h - 1) { y1 = h - 1; }
    const uint8_t *p00 = src + (y0 * w + x0) * 4;
    const uint8_t *p10 = src + (y0 * w + x1) * 4;
    const uint8_t *p01 = src + (y1 * w + x0) * 4;
    const uint8_t *p11 = src + (y1 * w + x1) * 4;
    // 面积权重(横向 × 纵向),和恒为 1
    double w00 = (1.0 - dx) * (1.0 - dy);
    double w10 = dx         * (1.0 - dy);
    double w01 = (1.0 - dx) * dy;
    double w11 = dx         * dy;
    for (int c = 0; c < 4; c++) {
        double v = w00 * p00[c] + w10 * p10[c] + w01 * p01[c] + w11 * p11[c];
        out[c] = (uint8_t)lround(fmin(fmax(v, 0.0), 255.0));   // 限幅+四舍五入
    }
}

#pragma mark - IAAffineTransform

@implementation IAAffineTransform

/// 复合正向矩阵:三明治夹层法,从右往左读 = 施加顺序
+ (simd_double3x3)matrixWithParams:(IATransformParams)params imageSize:(NSSize)size {
    double cx = (size.width  - 1.0) * 0.5;   // 离散像素网格的几何中心
    double cy = (size.height - 1.0) * 0.5;

    simd_double3x3 M = IAMatrixTranslation(-cx, -cy);                  // ① 中心→原点
    M = simd_mul(IAMatrixScale(params.scaleX, params.scaleY), M);      // ② 缩放
    if (params.transpose) {
        M = simd_mul(IAMatrixTranspose2D(), M);                        // ③ 转置(可选)
    }
    double mx = params.mirrorHorizontal ? -1.0 : 1.0;
    double my = params.mirrorVertical   ? -1.0 : 1.0;
    if (mx < 0.0 || my < 0.0) {
        M = simd_mul(IAMatrixScale(mx, my), M);                        // ④ 镜像(可选)
    }
    M = simd_mul(IAMatrixRotation(params.rotationDegrees), M);         // ⑤ 旋转
    M = simd_mul(IAMatrixTranslation(cx + params.translateX,
                                     cy + params.translateY), M);      // ⑥ 搬回+平移
    return M;
}

/// 反向映射执行变换:目标画布每像素用 M⁻¹ 反推源坐标再采样
+ (nullable IAImageBuffer *)warpImage:(IAImageBuffer *)src
                               matrix:(simd_double3x3)forward
                        interpolation:(IAInterpolation)interpolation
                           canvasMode:(IACanvasMode)canvasMode {
    if (!src) { return nil; }

    NSInteger sw = src.width, sh = src.height;
    NSInteger dw = sw, dh = sh;
    double offsetX = 0.0, offsetY = 0.0;

    if (canvasMode == IACanvasModeFit) {
        // Fit 模式:正向变换 4 个角,取包围盒作为新画布(矩形仿射像仍是矩形)
        double xs[4], ys[4];
        double cornerX[4] = {0.0, (double)sw - 1.0, 0.0,             (double)sw - 1.0};
        double cornerY[4] = {0.0, 0.0,              (double)sh - 1.0, (double)sh - 1.0};
        for (int i = 0; i < 4; i++) {
            simd_double3 p = simd_mul(forward, (simd_double3){cornerX[i], cornerY[i], 1.0});
            double wgt = (fabs(p.z) < 1e-12) ? 1.0 : p.z;   // 齐次归一化
            xs[i] = p.x / wgt;
            ys[i] = p.y / wgt;
        }
        double minX = xs[0], maxX = xs[0], minY = ys[0], maxY = ys[0];
        for (int i = 1; i < 4; i++) {
            minX = fmin(minX, xs[i]); maxX = fmax(maxX, xs[i]);
            minY = fmin(minY, ys[i]); maxY = fmax(maxY, ys[i]);
        }
        dw = (NSInteger)ceil(maxX - minX) + 1;
        dh = (NSInteger)ceil(maxY - minY) + 1;
        offsetX = minX;   // 包围盒左上角通常为负:转出画布的部分
        offsetY = minY;

        const NSInteger kMaxSide = 8192;   // 内存防线
        if (dw <= 0 || dh <= 0 || dw > kMaxSide || dh > kMaxSide) { return nil; }
    }

    // 奇异矩阵(如某方向缩放为 0)信息已丢失,无法反推;先拦再求逆
    if (fabs(simd_determinant(forward)) < 1e-12) { return nil; }
    simd_double3x3 inverse = simd_inverse(forward);

    IAImageBuffer *dst = [IAImageBuffer bufferWithWidth:dw height:dh];
    if (!dst) { return nil; }

    const uint8_t *sp = src.data;
    uint8_t *dp = dst.data;

    // 反向映射:遍历目标画布,反推源坐标(正向投射放大会留空洞)
    for (NSInteger yd = 0; yd < dh; yd++) {
        for (NSInteger xd = 0; xd < dw; xd++) {
            // Fit 模式:目标像素编号 + 包围盒偏移 = 世界坐标
            simd_double3 ps = simd_mul(inverse, (simd_double3){ (double)xd + offsetX,
                                                                (double)yd + offsetY, 1.0 });
            // 齐次归一化:仿射下 z≡1(空操作),透视变换时才真正起作用
            double wgt = (fabs(ps.z) < 1e-12) ? 1.0 : ps.z;
            double sx = ps.x / wgt;
            double sy = ps.y / wgt;

            uint8_t *out = dp + (yd * dw + xd) * 4;
            if (interpolation == IAInterpolationNearest) {
                IASampleNearest(sp, sw, sh, sx, sy, out);
            } else {
                IASampleBilinear(sp, sw, sh, sx, sy, out);
            }
        }
    }
    return dst;
}

@end
```

## 9. 附录：最小可运行 C 示例

脱离 macOS/simd 也能复现核心原理的极简实现（单文件、零依赖、C99），
可作为单元测试的参考对照物：

```c
#include <math.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

/* ---- 3x3 行主序矩阵 ---- */
typedef struct { double m[9]; } Mat3;
static Mat3 mat_mul(Mat3 A, Mat3 B) {
    Mat3 C;
    for (int r = 0; r < 3; r++)
        for (int c = 0; c < 3; c++)
            C.m[r*3+c] = A.m[r*3]*B.m[c] + A.m[r*3+1]*B.m[3+c] + A.m[r*3+2]*B.m[6+c];
    return C;
}
static Mat3 mat_translation(double tx, double ty) {
    return (Mat3){{1,0,tx, 0,1,ty, 0,0,1}};
}
static Mat3 mat_scale(double sx, double sy) {
    return (Mat3){{sx,0,0, 0,sy,0, 0,0,1}};
}
static Mat3 mat_rotation(double deg) {           /* 位图 y 向下:屏幕顺时针 */
    double r = deg * M_PI / 180.0, c = cos(r), s = sin(r);
    return (Mat3){{c,-s,0, s,c,0, 0,0,1}};
}
static Mat3 mat_centered(Mat3 core, double cx, double cy) {   /* 三明治夹层 */
    Mat3 to   = mat_translation(-cx, -cy);
    Mat3 back = mat_translation( cx,  cy);
    return mat_mul(back, mat_mul(core, to));
}
static double mat_det(Mat3 A) {
    return A.m[0]*(A.m[4]*A.m[8]-A.m[5]*A.m[7])
         - A.m[1]*(A.m[3]*A.m[8]-A.m[5]*A.m[6])
         + A.m[2]*(A.m[3]*A.m[7]-A.m[4]*A.m[6]);
}
static Mat3 mat_inverse(Mat3 A) {                /* 伴随矩阵法,3x3 专用 */
    double d = mat_det(A), id = 1.0 / d;
    Mat3 I = {{
        (A.m[4]*A.m[8]-A.m[5]*A.m[7])*id, (A.m[2]*A.m[7]-A.m[1]*A.m[8])*id,
        (A.m[1]*A.m[5]-A.m[2]*A.m[4])*id, (A.m[5]*A.m[6]-A.m[3]*A.m[8])*id,
        (A.m[0]*A.m[8]-A.m[2]*A.m[6])*id, (A.m[2]*A.m[3]-A.m[0]*A.m[5])*id,
        (A.m[3]*A.m[7]-A.m[4]*A.m[6])*id, (A.m[1]*A.m[6]-A.m[0]*A.m[7])*id,
        (A.m[0]*A.m[4]-A.m[1]*A.m[3])*id }};
    return I;
}

/* ---- 最近邻采样的反向映射 warp ---- */
/* src: RGBA8888;dst 需已分配 sw*sh*4 字节 */
void warp_nearest(const uint8_t *src, int sw, int sh,
                  uint8_t *dst, Mat3 forward) {
    Mat3 inv = mat_inverse(forward);
    for (int y = 0; y < sh; y++) {
        for (int x = 0; x < sw; x++) {
            /* P_source = M⁻¹ · P_target (齐次坐标) */
            double sx = inv.m[0]*x + inv.m[1]*y + inv.m[2];
            double sy = inv.m[3]*x + inv.m[4]*y + inv.m[5];
            long ix = lround(sx), iy = lround(sy);
            uint8_t *out = dst + (y*sw + x)*4;
            if (ix < 0 || ix >= sw || iy < 0 || iy >= sh) {
                out[0]=out[1]=out[2]=out[3]=0;              /* 图外 = 透明 */
            } else {
                const uint8_t *p = src + (iy*sw + ix)*4;
                out[0]=p[0]; out[1]=p[1]; out[2]=p[2]; out[3]=p[3];
            }
        }
    }
}

/* ---- demo:顺时针旋转 30° ---- */
int main(void) {
    const int W = 8, H = 8;
    uint8_t src[W*H*4], dst[W*H*4];
    for (int i = 0; i < W*H; i++) {                       /* 渐变测试图 */
        src[i*4+0] = (uint8_t)(i % W * 32);
        src[i*4+1] = (uint8_t)(i / W * 32);
        src[i*4+2] = 128; src[i*4+3] = 255;
    }
    Mat3 M = mat_centered(mat_rotation(30), (W-1)/2.0, (H-1)/2.0);
    warp_nearest(src, W, H, dst, M);
    for (int y = 0; y < H; y++) {                         /* 打印 alpha 网格 */
        for (int x = 0; x < W; x++) printf("%d", dst[(y*W+x)*4+3] ? 1 : 0);
        printf("\n");
    }
    return 0;
}
```

编译运行：`gcc demo.c -o demo && ./demo`（需要链接 `-lm` 时加上）。

## 附：验证清单

修改本模块后建议依次核对：

1. **恒等测试**：默认参数 warp，输出与输入逐字节一致；
2. **平移测试**：纯平移后图案位置精确偏移 (tx, ty)，无插值混色；
3. **90° 旋转测试**：宽高互换（Fit 模式），方向为屏幕顺时针；
4. **均匀缩放交换律**：R(35°)·S(1.4,1.4) 与 S(1.4,1.4)·R(35°) 逐像素一致；
5. **奇异拦截**：scaleX = 0 时 warp 返回 nil 而非垃圾图；
6. **边缘保留**：双线性模式下，图像最右列/最下行在任意变换后不出现
   整条透明缝（对应坑点 10 的回归测试）；
7. **顺序实验**：用 `TransformOrderPlayground.html` 可视化对比
   `T·R·S` 与 `S·R·T`，确认理解了从右往左的施加顺序。
