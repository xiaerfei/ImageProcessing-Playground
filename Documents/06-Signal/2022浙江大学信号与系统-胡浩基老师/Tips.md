# 整理听课笔记（`.tex`）的规则

适用于 `Documents/06-Signal/2022浙江大学信号与系统-胡浩基老师/` 下由视频转写整理出的 LaTeX 笔记。目标：把课堂记录变成可直接复习的讲义。

## 1. 内容：只留干货，不要啰嗦

- 不写「老师说」「课件」「板书」「转写」「视频时刻」「数据来自 PPT/黑板」「（补充）」「我核对过」「没查教材」「来源说明」「课堂讲评」「抽同学」「考试时…」等课堂口述与编者旁白，直接陈述结论。
- 删来源标注时，只去掉「谁说的、从哪来的」；数值、题目数据、结论本身必须留下。
- 保留：定义、公式、定理、证明、例题、示例图、表格、数值例子与验算。
- 例子要完整记录；「易错点」「作图要点」「题目辨析」这类实质提示改写后保留。
- 删掉空泛的总览/重复总结节（「一句话主干」「本节要记住的清单」）。
- 主要概念用「重点」框（`remember` 环境），不用「必须背下来」。

## 2. 结构与顺序

- 顺序：定义 → 定理 → 证明 → 例子。
- 必要的标题要分清楚，不要混在一起；标题去掉口语（「到底怎么理解」「（补充）」「老师课上的题」「回答老师留的悬念」「板书约 xx 分钟」等）。
- 证明分行写，不要挤在一行。

## 3. 配图

- 每个概念小节的定义后要配示例图；图注直接说明图中结论，不写「数据来自 PPT/黑板」。
- 横轴、竖轴都要标坐标刻度（刻度线 + 数字）。
- 刻度数字不能与曲线/火柴杆重叠（加白底），间距要够，必要时调大 TikZ 的 `x` 比例。
- 保留原有全部图、例题与表格，只改文字时不删结构。

## 4. 版式

- 移除标题下方的开头「说明」框（转写来源、模型版本、「（补充）」声明）。
- 清空页眉页脚，只在右下角保留页号：用 `fancyhdr` 重定义 `plain` 样式（`\fancyhf{}`、`\fancyfoot[R]{\thepage}`、去掉页眉页脚横线），正文起始处写 `\pagestyle{plain}`。
- 文件头 `% !TeX program` 等编译/来源注释保留：不渲染，不属于口述。
- 任务清单类文件（`Note.md`）不是笔记正文，不写进 `.tex`，也不入库。

## 5. 收尾检查

- `xelatex` 编译两遍（`bookmark` 书签需要两遍），确认无错误、无未定义引用、页数正常、页码在右下角。
- 关键页渲染成图片目视检查：图的形状、刻度、图注是否清楚。
- 结构数量核对：`figure` / `tikzpicture` / `remember` / `example` / `section` 数量与修改前一致，确保只删文字、不丢内容。
- 每次改动单独提交，提交信息用 `docs: ...`；不主动 push。

## 6. 整理方式

- 指定范围一次全部改完，不要逐条反问确认。
- 只动指定文件、指定范围；「其它部分暂时保持不变」。
- 拿不准是否属于口述时，按「这句话是否在讲概念」判断：讲概念就留下并改写成直接陈述，否则删。
