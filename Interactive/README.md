## 为什么单独放一个目录

这些页面**不进 PDF** —— PDF 生成只扫 `Documents/**/*.md`,
而交互这件事印在纸上等于没有。放在这儿是为了跟正文分开:
正文负责讲明白,这儿负责让你亲手拨一拨。

写新的时候沿用同一套约定:
配色跟 `Python-Prototyping/figkit.py` 里的图一致(蓝 `#2c6fbb`、红 `#c4442a`、
橙 `#d95f02`、绿 `#2a8f4a`),数值算法跟对应的 Python 脚本保持一致并在页脚注明是哪一个 ——
**两边对不上就是 bug。**
